# Bas de Best — Portfolio

A simple static portfolio website built with HTML and CSS.

## Run locally
Open `index.html` in a browser.

## Before publishing
Replace:
- `YOUR.EMAIL@example.com`
- `https://www.linkedin.com/in/YOUR-LINKEDIN/`
- `https://github.com/YOUR-GITHUB/`

Add project figures to `assets/` and link them from the project pages.

## Publish with GitHub Pages
Create a repository named `YOUR-GITHUB.github.io`, upload these files, then enable GitHub Pages under Settings → Pages.
